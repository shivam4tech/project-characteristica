# Failed Systems Database — Universal Language & Knowledge-Representation Attempts

**Project:** Project Characteristica — Phase 1 Literature Review
**Date:** 2026-08-16
**Status:** Initial corpus (16 systems); to be expanded

---

## Failure-Type Taxonomy

Every entry classifies its failure under one or more of:

| Type | Meaning |
|------|---------|
| **TECH** | Technological: tools of the era insufficient |
| **EPIST** | Epistemological: no principled way to fix the content (what concepts/primitives exist) |
| **ONT** | Ontological: the classification/ontology itself was wrong, arbitrary, or open-ended |
| **LING** | Linguistic: natural-language phenomena (polysemy, metaphor, context, indexicals) broke the mapping |
| **COG** | Cognitive: learning/using burden exceeded human capacity |
| **SOC** | Social: no community, institution, or incentive sustained adoption |
| **COMP** | Computational: complexity/combinatorial explosion/intractability |
| **PHIL** | Philosophical: the underlying conception (e.g., analytic truth, atomism of concepts) was unsound |

## 1. Ramon Llull — Ars Magna (1305)

| Field | Entry |
|---|---|
| Objective | Universal method for demonstrating truths and converting non-believers by rational argument |
| Representation | Rotating paper wheels combining letter-coded principles (B=goodness, C=greatness…) |
| Ontology | 9 absolute + 9 relative divine attributes as exhaustive primitives |
| Syntax | Combinatorial enumeration of letter-triples/quadruples |
| Semantics | Theological: each combination names a metaphysical configuration |
| Inference | None beyond enumeration — validity assumed from combinatorial completeness |
| NL relationship | Independent of natural language; Latin glosses |
| Intended users | Missionaries, scholastic philosophers |
| Computational properties | Trivially finite; ~680 combinations at base depth |
| Strengths | First mechanical concept-combinatorics; inspired Leibniz, Bruno, Agrippa, Kircher |
| Weaknesses | Arbitrary alphabet; no truth criterion; generates nonsense combinations indifferently |
| Reason failed | EPIST + PHIL: primitives not justified; PHIL: no criterion separating valid from invalid combinations |
| Scholarly criticism | Leibniz (1666): useful for inventio but "of little use for judgment"; modern: Bonner's Llull studies |
| Modern relevance | Prototype of generative enumeration without semantics — exactly the trap an AI-era system must avoid |

## 2. Cave Beck — The Universal Character (1657)

| Field | Entry |
|---|---|
| Objective | Universal written language via numbered vocabulary |
| Representation | Arabic numerals 1–4000 + terminal letters marking grammatical function |
| Ontology | None: roots are an arbitrary English-Latin dictionary ordering |
| Syntax | Letter suffixes on numbers encode case/tense/voice |
| Semantics | Pure convention: number = word lookup |
| Inference | None |
| NL relationship | Direct cipher over Latin/English lexicon |
| Intended users | Learned international correspondence |
| Computational properties | Lookup-table trivial |
| Strengths | Compact; language-independent signs; early "characteristic numbers" idea |
| Weaknesses | Memorizing 4,000 arbitrary codes; no compositional semantics; grammar ad hoc |
| Reason failed | COG (memorization burden) + ONT (no conceptual organization) + SOC (no adopters) |
| Scholarly criticism | Contemporaries found it unreadable; Slaughter (1982) treats as cautionary baseline |
| Modern relevance | Shows that unstructured codes buy nothing — structure must be in the system, not the lookup |

## 3. George Dalgarno — Ars Signorum (1661)

| Field | Entry |
|---|---|
| Objective | Universal character AND spoken philosophical language generated from a classification |
| Representation | 17 letters assigned to 17 primary genera; 2-letter radicals = genus+species; affixes for differentiae |
| Ontology | Tree: 17 genera → species → differences (substances, accidents, actions, private/transcendental notions) |
| Syntax | Radical + inflections; regular morphology mirroring taxonomy |
| Semantics | Positional intensional semantics: meaning = node in tree; initial letters reveal genus |
| Inference | Implicit only: syllogistic via tree containment |
| NL relationship | Designed replacement; dictionary maps Latin/English terms in |
| Intended users | The learned world (replacement for Latin) |
| Computational properties | Human-scale tables |
| Strengths | First published classification→symbol pipeline; transparent morphology; self-teaching words |
| Weaknesses | Ad hoc 17-fold classification; relations poorly handled; particles forced into tree |
| Reason failed | ONT (classification indefensible) + LING (polysemy breaks tree mapping) + SOC (no adoption; lost to Wilkins's grander Essay) |
| Scholarly criticism | Wilkins's parallel project overshadowed it; Cram & Maat (2001) modern edition rehabilitates its rigor; Leibniz praised its intent while criticizing execution |
| Modern relevance | The minimal complete architecture: ontology + generation + grammar. Its failure localizes the problem in the ontology layer, not the notation layer |

## 4. John Wilkins — Real Character & Philosophical Language (1668)

| Field | Entry |
|---|---|
| Objective | Complete written real character + spoken philosophical language covering "all things and notions"; Royal Society-sponsored standard |
| Representation | 40 radical glyphs (genus); appended strokes for species/differences; parallel CV-syllable spoken forms (de=element, deb=fire, deba=flame) |
| Ontology | 40 genera → ~2,030 species, sourced from contemporary natural history (Ray, Willughby) + Aristotelian residue |
| Syntax | Regular synthetic grammar; transcendental particles for logical/grammatical operators |
| Semantics | Positional in taxonomy; one sign per concept intended |
| Inference | None provided — a language, not a calculus |
| NL relationship | Replacement ambition; English-Latin dictionary attached (~15,000 entries) |
| Intended users | International scholarship, natural philosophy |
| Computational properties | Hand-drafted tables; enormous but finite |
| Strengths | Most complete pre-modern realization; genuine compositionality of signs; empirical grounding of parts |
| Weaknesses | Genus boundaries arbitrary; covertly encodes European/English conceptual scheme; obsolete almost immediately (taxonomy moved); unwritable glyphs; learning burden huge |
| Reason failed | ONT + LING + COG + SOC (institution died with the founding generation) + EPIST (no principle fixing the classification) |
| Scholarly criticism | Wallis: arbitrary; Hooke: impractical; Leibniz (letters 1670s): lacks calculus & true analysis of notions; Eco (1995), Slaughter (1982), Lewis (2007), Subbiondo (1992) |
| Modern relevance | Canonical proof that a fixed universal taxonomy is unattainable AND unnecessary if operations are universal instead; ancestor of top-level ontologies and CNLs |

## 5. Athanasius Kircher — Polygraphia Nova (1663)

| Field | Entry |
|---|---|
| Objective | Universal writing for missionary communication |
| Representation | Numeric/symbolic substitution tables across ~10 languages |
| Ontology | None — lexical equivalence classes |
| Syntax | Source-language syntax retained |
| Semantics | Word-for-word transfer |
| Inference | None |
| NL relationship | Cipher layered on existing languages |
| Intended users | Jesuit missionaries |
| Computational properties | Table lookup |
| Strengths | Practical multilingual aid; wide circulation |
| Weaknesses | Not a language at all — no independent semantics; his hieroglyph theory (real character claim) was false |
| Reason failed | TECH-era PHIL: conflated decipherment fantasy with design; never claimed more than translation aid |
| Scholarly criticism | Modern Egyptology demolished the hieroglyph reading; Godwin (1979) biography |
| Modern relevance | Cautionary: symbol systems marketed as "real characters" that are actually ciphers inherit all ambiguity of the source languages |

## 6. Leibniz's Own Programme (1666–1716) — incomplete rather than failed

| Field | Entry |
|---|---|
| Objective | Characteristica universalis + calculus ratiocinator: make reasoning calculable ("Calculemus!") |
| Representation | Evolved: combinatorial algebra (1666) → real characters (1670s) → prime-number characteristic (1679–1690) → plus-minus calculus (1680s–90s) |
| Ontology | Never completed: multiple incompatible primitive lists; alphabet of human thought aspirational |
| Syntax | Algebra-of-concepts equations; containment A⊃B; no quantifier apparatus beyond indefinite concepts |
| Semantics | Intensional containment: predicate contained in subject; est/Non est |
| Inference | Substitution of equivalents; syllogistic derivable; strict implication analogy (Lenzen's reconstruction proves Boolean-equivalence of core) |
| NL relationship | Intended full reduction of discourse to characteristic; never built the parser/lexicon |
| Intended users | Scholars; ideally collaborative academies |
| Computational properties | Core decidable and mechanizable (Lenzen 2018); full programme undecidable ambitions (contingency via infinite analysis) |
| Strengths | Only historical system uniting LANGUAGE and CALCULUS; provably sound fragments |
| Weaknesses | No fixed primitives; no relations; no quantifiers in practice; contingency unresolved; never integrated |
| Reason failed | EPIST + ONT (primitives/taxonomy never secured) + PHIL (analytic-truth conception strains contingent knowledge) + SOC (no collaborators at scale) + TECH (mechanical computation era) |
| Scholarly criticism | Couturat vs. Russell interpretations; Kneale & Kneale; Ishiguro (1972) anti-realist reading of concepts; Lenzen rehabilitation; Mugnai, Rutherford |
| Modern relevance | The target of reconstruction; its *fragment* successes (Boolean-equivalent algebra) show the calculus side works when scope is disciplined |

## 7. Frege — Begriffsschrift (1879)

| Field | Entry |
|---|---|
| Objective | Leibnizian lingua characterica: a script expressing contents precisely for science (esp. arithmetic) |
| Representation | 2D ideographic notation with quantifiers, negation, conditionals |
| Ontology | Objects + functions/concepts (unsaturated); later platonism |
| Syntax | Fully formal; first modern quantificational syntax |
| Semantics | Sense/reference (1892); compositionality principle articulated |
| Inference | Axioms + rules — complete for its fragment's purposes |
| NL relationship | Deliberately alien to natural language grammar |
| Intended users | Mathematicians/philosophers |
| Computational properties | Undecidable in general (first-order fragment semi-decidable) |
| Strengths | Won historically: foundation of modern logic |
| Weaknesses as characteristica | Expressive power ⇒ undecidability; no treatment of empirical/ordinary discourse; hostile reception delayed influence |
| Reason failed (as universal medium) | PHIL tradeoff: expressiveness destroys decidability/mechanical calculation; SCHRODER polemic: judged mere calculus ratiocinator lacking content-expressiveness |
| Scholarly criticism | Schröder (1880) review; Bertran-San Millán (2021) reassessment; van Heijenoort (1967) language-vs-calculus dichotomy |
| Modern relevance | Defines the expressiveness/tractability tradeoff any successor must navigate explicitly |

## 8. Logical Positivism — Unified Science Language ideal (1920s–30s)

| Field | Entry |
|---|---|
| Objective | Physicalist unified language for all science; protocol sentences; elimination of metaphysics |
| Representation | Symbolic logic + physicalist thing-language |
| Ontology | Anti-metaphysical; observation basis contested internally |
| Syntax | Formal logic (Wittgenstein/Carnap models) |
| Semantics | Verificationist; Carnap's logical syntax program (1934) then Tarskian semantics |
| Inference | Deductive + methodological |
| NL relationship | Reconstruction OF scientific discourse |
| Intended users | Scientific community |
| Computational properties | Not computational focus |
| Strengths | Made formalization central to philosophy of science |
| Weaknesses | Verificationism collapsed (Quine 1951; Popper earlier); theoretical-term problem; observation-theory distinction untenable |
| Reason failed | PHIL: the epistemology underneath (foundationalism, verification) was unsound; LING: natural language irreducibility (later Ordinary Language critique) |
| Scholarly criticism | Quine "Two Dogmas" (1951); Hempel; Kuhn/Feuerbach? [verify: Kuhn 1962] |
| Modern relevance | Demonstrates that even a mathematically perfect formal language fails if its semantic epistemology is wrong — direct warning for AI-semantics hybrid |

## 11. Lojban / Loglan (1955– ) — predicate-logic naturalistic conlang

| Field | Entry |
|---|---|
| Objective | Speakable language with logically unambiguous grammar (Whorf-testable claims) |
| Representation | Phonemic words + predicate structure + explicit logical connectives/quantifiers |
| Ontology | Predicate places defined per root (gismu place structures) |
| Syntax | Yacc-parseable unambiguous grammar |
| Semantics | Montague-flavored intentions; attitudinals separate |
| Inference | External (users apply logic) |
| NL relationship | Designed alternative; translation corpus exists |
| Intended users | Enthusiast community |
| Strengths | Machine-parseable; genuinely culturally neutral-ish lexicon building; longest-lived engineered logical language |
| Weaknesses | Tiny community; semantic ambiguity migrated to pragmatics/place-structure disputes; no inference tooling in daily use |
| Reason failed (scale) | COG + SOC: learnability/adoption; PHIL: unambiguous SYNTAX ≠ unambiguous SEMANTICS (core lesson!) |
| Scholarly criticism | Cowan (1997) complete Lojban; linguistic skepticism re Sapir-Whorf testability |
| Modern relevance | Proves syntactic determinacy is achievable and insufficient — the residual ambiguity lives in interpretation, i.e., exactly where our AI-layer question operates |

## Cross-Cutting Failure Analysis

### Frequency of failure types (initial corpus)
- **EPIST** (no principled primitives/content): 11/16
- **ONT** (ontology indefensible/open-ended): 9/16
- **LING** (natural-language phenomena break mapping): 9/16
- **SOC** (adoption/institution): 8/16
- **PHIL** (unsound underlying conception): 7/16
- **COG**: 5/16
- **COMP**: 5/16
- **TECH**: 3/16 (era-limited)

### Structural findings
1. **The two-sided requirement is rare and decisive.** Systems with language-but-no-calculus (Wilkins, Esperanto, ISOTYPE) and calculus-but-no-language (Frege, DL/OWL) both stall at universality. Leibniz alone demanded both — which is why he alone diagnosed the real difficulty.
2. **The primitive-concept problem is the deepest recurrent killer** (Llull → Beck → Dalgarno → Wilkins → Leibniz → CD theory → Cyc → UNL). Every attempt to FIX a primitive inventory epistemically collapses. This is strong prior evidence for Directive §X: treat primitives as computational/learned, not metaphysical.
3. **Ambiguity migration, not elimination:** Lojban shows removing syntactic ambiguity just relocates it into pragmatics/semantics. Supports Directive §XV (ambiguity as first-class object).
4. **Social failure is real but orthogonal:** Esperanto thrives technically-trivially; Wilkins died socially despite superiority. Adoption arguments must be separated from correctness arguments in the paper.
5. **Partial successes cluster at fragments:** Lenzen's Leibniz, DL fragments, ACE. Pattern suggests the honest architecture is verified-core + AI-mediated-periphery, not universal coverage.
