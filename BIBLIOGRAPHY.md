# Bibliography

Canonical source registry for Project Characteristica. Rules:

- One entry per unique source; before adding, check for an existing entry (Curator enforces dedup).
- Every ledger claim and literature note must reference entries from this table by Source ID.
- Reliability ratings: `high` (primary text / peer-reviewed / official docs), `medium` (reputable secondary scholarship), `low` (unverified — usable only for discovery leads, never as evidence).

## Schema

| Field | Meaning |
|---|---|
| Source ID | `S-NNN` sequential |
| Citation | Full citation |
| Author(s) | |
| Date | Original publication date/year |
| Type | book / paper / primary-text / documentation / dataset / webpage |
| Tier | primary / secondary |
| URL/DOI/Archive | identifier where relevant |
| Domain | e.g., history of logic, interlingua MT, semantic parsing, prompt compression |
| Associated system | e.g., characteristica universalis, ARPA interlingua projects, AMR |
| Pages/sections examined | filled in as work proceeds |
| Reliability | high / medium / low |
| Relevance | which question/hypothesis/workstream this serves |
| Notes | caveats, editions used |
| Used by | agent roles that cited it |
